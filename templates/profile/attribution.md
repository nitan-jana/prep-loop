# Attribution

Who did what, on every project the user talks about. Settled once, here, so
that no story or deep dive has to settle it again.

The test for every line: **does this phrasing survive someone opening the
source mid-answer.** See [`policy/claims.md`](../../policy/claims.md#the-attribution-boundary).

## Excluded from enumeration

Anything the system may not read, count or name. Set once, before the first
claim is written, and honoured by every enumeration afterwards.

Wider than repositories: an employer's name, a client's name, a product never
announced, a project with no repository at all.

| Excluded | Kind | Because |
|---|---|---|
| <what> | <repository / employer / client / product / project> | <under agreement / client work / someone else's> |

**An excluded entry is not named anywhere**, including in a note saying
something was excluded. A row here is the only place it appears.

This is a different question from the steer-away list in
[`projects.md`](projects.md), which is about what to volunteer in a room. This
one is about what may go on disk at all.
