# Showcase questions

What the user asks the interviewer. Prepared, because "any questions for us"
arrives at the end of an hour, when nothing is being invented well.

A question here does two things at once: it gets an answer worth having, and it
shows what the person asking pays attention to. A question that only does the
second is a performance and reads as one.

| Question | Ask it of | What the answer would change |
|---|---|---|

The last column is the filter. A question whose answer changes nothing about
whether the user wants the job is a question worth cutting, however good it
sounds.

## Do not ask

Questions that are answered on the careers page, and questions that only look
sharp. Written down because both are tempting in the moment.
