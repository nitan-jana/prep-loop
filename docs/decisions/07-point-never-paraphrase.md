# Point, never paraphrase

A file may link a rule, or override it with a stated reason. It may not restate
it. Two copies of a rule is one rule and one future bug, and where a file
appears to contradict something it links, **the linked file wins and the linking
file is the defect**.

## It had to be applied to the file that states it

`CLAUDE.md` originally carried the three artifact-voice rules in full, numbered,
with their reasons — a second copy of `policy/artifact-voice.md` living in the
file loaded into every session. It was cut down to the three names and a link.

The compromise is stated in place: this file is loaded into every session and a
policy file is not, so the *names* have to be in reach. The bodies stay in one
place. That is the shape of every later exception too — a skill's `## Forbidden`
list names the rule in a phrase and links the file that argues for it, so it can
be glanced at mid-round without becoming a rival copy.

Skills were later swept the same way, replacing restated paragraphs with the
link and one clause.

## Extraction is the other half

When a rule turns out to belong to two files, it gets its own:

- **Claims** came out of story craft. The markers, verify-before-writing and the
  attribution boundary were written for stories, then needed by the profile, the
  deep dives and the outbound artifacts. Story craft now links.
- **Outbound** came out of caps. A limit answers how often; nothing in a limit
  says what a good action looks like. `caps.md` keeps the ceiling and hands off
  the mechanism.
- **Recall** came out of the mock loop. It was one round inside a file about
  running a loop, which is why every rule it needed had to be justified against
  the loop's window. Given its own file it is a session with its own pool, its
  own edge and its own record, and `mocks.md` keeps only the sentence saying it
  is not the loop's job.

## The related failure it names

**A file answers its own question.** Material belonging in another file does not
get parked here with a note admitting as much. If a sentence begins by saying it
belongs somewhere else, it does — move it or drop it, because writing it down
anyway makes the other file wrong by omission while looking scrupulous about it.
