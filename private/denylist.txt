# Terms that must never appear in the shareable half of this repo.
#
# Read by tools/leak-check.ts. Personal — never one of the directories copied
# out when publishing.
#
# Every term here is derived from a fact in profile/. As a name, employer,
# domain, school, city or figure is confirmed there, the term is added here in
# the same step. Terms and profile that drift apart are a denylist that passes
# a leak.
#
# Format
#   one term per line, matched case-insensitively as a substring
#   a line starting with `re:` is a regular expression instead
#   blank lines and `#` comments are skipped
#
# Keep terms specific enough not to cry wolf. A term that fires on ordinary
# prose gets the script switched off, which is worse than not having it. Short
# figures should be word-bounded — `re:\b147\b`, not `147`.
#
# One entry is a random canary token, written into a single file under profile/.
# It catches a whole file being copied into the shareable half, which term
# matching alone would miss. Unique per instance: a token shipped with the
# toolkit would be identical for everyone and would prove nothing.
